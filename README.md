# CipherForge

CipherForge is a desktop cryptography workbench built with Python and Tkinter.

It provides an interactive interface for AES-256-ECB encryption and decryption, ciphertext inspection, visualization, and file encryption/decryption.

## Features

- AES-256 encryption
- AES-256 decryption
- Secure random key generation
- Base64 key representation
- PKCS#7 padding
- Text encryption and decryption
- File encryption and decryption
- Base64 ciphertext viewer
- Hexadecimal dump
- Binary representation
- Byte matrix visualization
- ECB block visualization
- Data/package map
- Cyber-security themed GUI

## Technology Stack

- Python
- Tkinter
- PyCryptodome
- AES-256
- Base64
